Handy Viz Tool

This is a tool for mathematical visualization based on jReality and the plugin system jrworkspace. The following plugins are available to assist your viewing pleasure. Use the menu item "Window->Left slot", etc., to make visible a particular plugin panel (in this case, the one to the left of the 3D graphics window) if it is not visible.

  • Tool bar: at the right end of the tool bar are a set of tools for interacting with the 3D scene. Be patient, there are tooltips.
  • Left slot: this is the application-specific panel, for interacting with the specific mathematical content featured in the application.
  • Right slot: this displays the Navigator, a tree model for the displayed scene graph.
  • Top slot: a key-frame animation tool for animating scene graph transformations and camera settings.
  • Bottom slot: a bean shell, for interacting with the current selection (use selection tool from tool bar, or the Navigator, to change selection.)
  • Help menu for 3D window: type the 'h' key to toggle display of a "heads-up" display of all keyboard shortcuts available in the 3D graphics window. JOGL backend only)
  • Performance statistics: type 'i' key to toggle display of performance information via a "heads-up" display. (JOGL backend only)
